01 / Start with the work

Example organization: Harbor Community Services
Working session: Finance lead, program lead, system administrator
Scope: One fictional purchasing request workflow

Service goal: Help staff submit complete requests and route them to an authorized reviewer. Confirm decisions before configuration begins.

02 / Trace one request

PromptFictional example response
What starts the process?A program coordinator needs $750 in workshop supplies.
What must accompany it?Business purpose, program/cost coding, amount, and a quote.
Who can decide?Program manager: up to $1,000. Finance director: above $1,000. No self-approval.
What if it is incomplete?Return to requester with a specific correction; requester updates and resubmits.
What needs confirmation?Who covers an absent reviewer, and how that authority is documented.
